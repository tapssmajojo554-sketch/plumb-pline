# Plumb Line Campaign

A static one-page advertising landing page for Plumb Line, based on the public source site and intended for GitHub Pages or any static host.

## Local preview

```bash
python3 -m http.server 3000 --directory public
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```

The generated static output is in `dist/`. The same command also creates `docs/`, a ready-to-select GitHub Pages output folder. In the repository’s Pages settings, choose **Deploy from a branch**, select `main`, and choose `/docs` as the folder.
